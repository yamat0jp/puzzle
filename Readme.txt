
　アルゴリズムを学ぼうと思い電子書籍「パズルで鍛えるアルゴリズム力」を随分前に購入していました。やりたいことではないな、と当時読みもせず積ん読しておいたのですが執筆の題材探しで偶然見つけたので解いてみました。
　それも初めのテーマから逆ポーランド記法でありやる気は全然起きませんでしたが、次のテーマ小町算を読んだときPython4Delphiで実装したらまさかの展開になるなとおもってそれなら興味を持てました。書いて動かしてみたらアルゴリズムとの勝負なんて出来るわけも無く大変遅い冷めたピザのようなリゾルバができあがりました。そこで終わりにならずに、コンパイラで昔に学習した逆ポーランド記法を実装してやろうじゃ無いかと思い立つことが出来たため本の内容を読んで理解を深めることが出来ました。探索の話なんですがポーランド記法のパターンを絞って紙面を節約しながらというか創意に満ちたコードを作っておられたので参考にしながら自作するに至りました。
　動画にてアルゴリズムが動作する様子をアップロードしましたが、これだけでは伝わりようが無いと不安になったのでgithubでソースコードを公開する方法は無いか考えていました。ダウングレードと呼ぶべき記述量の削減をして処理能力は骨抜きにしてしまいましたが、かなり原作とは違う表現となっておりこれなら公開に踏み切れると思いアップロードしておきます。原本は公開されている書籍だけに内容はしっかりしており私が今回作成したアルゴリズムよりも工夫があります。
